# Простые типы данных в Python

## 1. Что такое тип данных и зачем он нужен

**Тип данных** определяет, *что это за значение* и *что с ним можно делать*.
`5 + 5` даёт `10`, а `"5" + "5"` даёт `"55"` — значения похожи, но типы разные, поэтому и поведение разное.

Узнать тип любого значения можно функцией `type()`:

```python
print(type(100))     # <class 'int'>
print(type(100.0))   # <class 'float'>
print(type("100"))   # <class 'str'>
```

### Статическая и динамическая типизация

- **Статическая** (C, Java, Go): тип переменной указывается при объявлении, и в неё можно класть *только* значения этого типа.
- **Динамическая** (Python): тип указывать не обязательно, и в одну и ту же переменную можно положить значение другого типа.

```python
value = 123      # сейчас value указывает на int
value = "123"    # а теперь на str — Python не возражает
```

Переменная в Python — это **бирка (ссылка)**, которую вешают на объект в памяти. Сам объект имеет тип, а бирку можно перевесить на любой другой объект.

### Аннотации типов

Тип можно подписать «для себя» и для редактора кода — это **аннотация**:

```python
age: int = 25
name: str = "Анна"
```

Python аннотации **не проверяет**: `age: int = "двадцать"` выполнится без ошибки. Это подсказка для людей и инструментов (IDE, mypy), а не правило.

### Сколько места занимает объект

```python
from sys import getsizeof

print(getsizeof(5))          # размер объекта в байтах
print(getsizeof("a" * 100))  # чем длиннее строка, тем больше
```

Точные числа зависят от версии Python и системы. Главное: у `int` и `str` размер растёт вместе со значением, у `float` — фиксированный.

## 2. `int` — целые числа

```python
age = 25
debt = -3
big = 1_000_000   # подчёркивания только для читаемости, это просто 1000000
```

Целые числа в Python **не ограничены по размеру** — можно хранить сколь угодно большое число (пока хватает памяти).

Основные операции:

| Операция | Пример | Результат |
|---|---|---|
| сложение | `7 + 2` | `9` |
| вычитание | `7 - 2` | `5` |
| умножение | `7 * 2` | `14` |
| деление | `7 / 2` | `3.5` ← всегда `float`! |
| целочисленное деление | `7 // 2` | `3` |
| остаток от деления | `7 % 2` | `1` |
| степень | `7 ** 2` | `49` |

## 3. `float` — дробные числа (с плавающей точкой)

```python
pi = 3.14159
temperature = -2.5
```

Разделитель — **точка**, а не запятая.

### Проблема точности

```python
print(0.1 + 0.2)          # 0.30000000000000004
print(0.1 + 0.2 == 0.3)   # False
```

Компьютер хранит `float` в двоичном виде, а числа вроде `0.1` в двоичной системе — бесконечная дробь (как 1/3 = 0.333… в десятичной). Поэтому хранится приближённое значение, и мелкие ошибки накапливаются.

Округлить для вывода можно через `round(x, n)`:

```python
print(round(0.1 + 0.2, 2))   # 0.3
```

**Вывод:** `float` подходит для физики, измерений, графики, но **не для денег**.

## 4. `str` — строки

Строка — это **последовательность символов**.

```python
name = "Анна"
message = 'Привет!'           # одинарные и двойные кавычки равноправны
text = "Он сказал: 'Привет'"  # кавычки другого вида внутри — без проблем
multi = """Это
несколько
строк"""
```

Полезное:

```python
city = "Москва"
print(len(city))      # 6 — длина строки
print(city[0])        # 'М' — первый символ (счёт с нуля!)
print(city[-1])       # 'а' — последний символ
print(city.upper())   # 'МОСКВА'
print("a b c".split(" "))   # ['a', 'b', 'c'] — разбить строку на список
```

### Склейка строк и f-строки

```python
name = "Bob"
age = 23

print("Моё имя " + name)                     # конкатенация: str + str
print(f"Моё имя {name}, мне {age} лет")      # f-строка — удобнее всего
```

## 5. Конвертация (приведение) типов

Типы можно превращать друг в друга функциями `int()`, `float()`, `str()`, `bool()`:

```python
str(123)       # '123'
str(1.5)       # '1.5'
int("42")      # 42
float("3.14")  # 3.14
int(3.99)      # 3 — дробная часть отбрасывается, НЕ округляется
```

Сложить строку и число напрямую нельзя:

```python
"Мне " + 23 + " года"          # TypeError: can only concatenate str (not "int") to str
"Мне " + str(23) + " года"     # 'Мне 23 года'
```

Если строку нельзя превратить в число — будет ошибка:

```python
int("abc")    # ValueError
int("3.5")    # ValueError — сначала float("3.5"), потом int(...)
```

Это можно использовать, чтобы найти числа в тексте:

```python
words = "Моё 25 имя Bob123 и мой возраст 23".split(" ")
for word in words:
    try:
        print(int(word))     # напечатает 25 и 23
    except ValueError:
        pass                 # не число — пропускаем
```

## 6. `bool` — логический тип

Всего два значения: `True` (истина) и `False` (ложь). Пишутся **с большой буквы**.

```python
is_student = True
has_job = False
```

`bool` получается в результате **сравнений**:

| Оператор | Смысл | Пример | Результат |
|---|---|---|---|
| `==` | равно | `2 == 2` | `True` |
| `!=` | не равно | `2 != 2` | `False` |
| `>`, `<` | больше, меньше | `5 > 3` | `True` |
| `>=`, `<=` | больше/меньше или равно | `3 <= 3` | `True` |

Не путать: `=` — присваивание, `==` — сравнение.

Логические операторы: `and` (и), `or` (или), `not` (не):

```python
age = 20
has_ticket = True
print(age >= 18 and has_ticket)   # True
```

`bool` — основа условий:

```python
age = 21
if age > 18:
    print("взрослый")   # выполняется, если условие True
else:
    print("ребёнок")    # выполняется, если условие False
```

«Пустые» значения считаются ложью: `bool(0)`, `bool("")`, `bool(None)` → `False`. Всё остальное — истина, даже `bool("0")` → `True`.

## 7. `None` — «ничего»

`None` означает **отсутствие значения**: оно ещё неизвестно, не задано или не найдено.

```python
discount = None        # скидки пока нет
user_address = None    # адрес пользователь не указал

print(type(None))      # <class 'NoneType'>
```

`None` — это не `0` и не пустая строка `""`. Это отдельный объект, «пустое место».

Проверять на `None` принято через `is`:

```python
if discount is None:
    print("Скидки нет")
```

## 8. `Decimal` — точные десятичные числа (деньги)

`Decimal` из стандартного модуля `decimal` хранит числа в десятичном виде, поэтому считает точно.

```python
from decimal import Decimal

print(Decimal("0.1") + Decimal("0.2"))                    # 0.3
print(Decimal("0.1") + Decimal("0.2") == Decimal("0.3"))  # True

price = Decimal("19.99")
tax = Decimal("0.07")
print(price + price * tax)    # 21.3893
```

Важно:

- Создавать `Decimal` нужно **из строки**: `Decimal("0.1")`. Если передать `float` — `Decimal(0.1)`, — в него попадёт уже неточное значение `0.1000000000000000055511…`.
- `Decimal` нельзя напрямую складывать с `float` — будет `TypeError`. С `int` — можно.

**Где применяется:** деньги, бухгалтерия, банковские расчёты — везде, где копейка должна сходиться.

## 9. timestamp — как компьютер хранит время

**timestamp** — это количество секунд, прошедших с **1 января 1970 года 00:00:00 UTC** (так называемая «эпоха Unix»). Отдельного типа нет: в Python это обычный `float` (или `int`).

```python
import time
from datetime import datetime

now = time.time()
print(now)          # например 1759577400.123456
print(type(now))    # <class 'float'>
```

Почему так удобно: время — это просто число, его легко хранить, сравнивать и вычитать.

```python
start = time.time()
# ... какая-то работа ...
print(f"Прошло {time.time() - start} секунд")
```

Перевод в читаемый вид:

```python
print(time.ctime(now))                     # 'Sat Oct  4 14:30:00 2026'

dt = datetime.fromtimestamp(now)           # объект datetime в местном часовом поясе
print(dt.strftime("%Y-%m-%d %H:%M:%S"))    # '2026-10-04 14:30:00'
```

Коды форматирования: `%Y` — год, `%m` — месяц, `%d` — день, `%H` — часы, `%M` — минуты, `%S` — секунды.

## Шпаргалка

| Тип | Пример | Для чего |
|---|---|---|
| `int` | `25`, `-3`, `1_000_000` | счётчики, количество, индексы |
| `float` | `3.14`, `-2.5` | измерения, приближённые расчёты |
| `str` | `"Анна"`, `'текст'` | любой текст |
| `bool` | `True`, `False` | условия, флаги «да/нет» |
| `None` | `None` | «значения нет» |
| `Decimal` | `Decimal("19.99")` | деньги, точные расчёты |
| timestamp | `time.time()` | момент времени в секундах |
